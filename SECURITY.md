# Security Policy

> **Project:** ShadowRealm 3D — v3.0 Ascendant | **Category:** Security & Legal | **Last Updated:** 20/11/2026

Supported versions and responsible vulnerability reporting.

## Supported Versions

| Version | Supported |
|---|---|
| `3.0.x` | Yes |
| `< 3.0` | No |

## Reporting a Vulnerability

Do not disclose active exploits in public issues. Use GitHub Private Security Advisories and follow `VULNERABILITY_DISCLOSURE.md` and `security_spec.md`.
