# Spirit Roots

> **Project:** ShadowRealm 3D — v3.0 Ascendant | **Category:** Cultivation, Worldbuilding & Game Systems | **Last Updated:** 2026-11-25

Elemental affinities aligned with the four playable archetypes.

## Affinities

- **Earth/Gold Root (Knight):** Stun-focused `Aegis Cleave`.
- **Frost/Flame Dual Root (Mage):** `Frostfire Nova` applying Freeze + Burn.
- **Wood/Venom Root (Rogue):** High-agility `Venom Flurry`.
- **Cinder/Soul Root (Shaman):** Sustained Burn via `Cinder Totem`.
