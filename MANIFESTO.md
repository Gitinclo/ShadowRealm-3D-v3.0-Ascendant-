# Manifesto

> **Project:** ShadowRealm 3D — v3.0 Ascendant | **Category:** Core Repository & Governance | **Last Updated:** 2026-11-25

Core convictions guiding ShadowRealm 3D engineering and game design.

## Engineering Tenets

1. **Zero Black-Box Bloat:** Prefer transparent C++17, explicit shader pipelines, and header-only engines (`Causality.h`).
2. **Determinism First:** Combat formulas, AI state machines, and Causality rules must remain verifiable via automated tests.
3. **Playable Over Theoretical:** Every target listed in `CMakeLists.txt` or `package.json` must build cleanly from source.

## Player-First Design

Respect player agency through responsive combat, readable telegraphs, meaningful progression from Level 1 to Domain Level 999, and offline-capable play.
