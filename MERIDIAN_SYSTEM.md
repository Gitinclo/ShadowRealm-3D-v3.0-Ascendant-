# Meridian System

> **Project:** ShadowRealm 3D — v3.0 Ascendant | **Category:** Cultivation, Worldbuilding & Game Systems | **Last Updated:** 2026-11-25

Internal energy channels governing class stat growth.

## Channel Mapping

- **Iron Vein (STR):** Scales primary strikes, Class Powers, and crit ceilings.
- **Bastion Vessel (DEF):** Feeds asymptotic damage mitigation `100 / (100 + DEF * 2.5)`.
- **Gale Meridian (AGI):** Elevates critical strike chance up to the 65% cap.
