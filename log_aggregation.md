# Log Aggregation

> **Project:** ShadowRealm 3D — v3.0 Ascendant | **Category:** SRE, DevOps & Operational Discipline | **Last Updated:** 2026-11-25

Retention and indexing standards for CI and optional server logs.

## Standards

Use ISO-8601 timestamps, severity levels (`INFO`, `WARN`, `ERROR`), component tags, and scrub any tokens or host secrets prior to storage.
