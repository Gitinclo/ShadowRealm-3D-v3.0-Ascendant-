Quickstart

Build & Play

Clone the repository and compile natively with CMake 3.16+ and a C++17 compiler.

# Desktop (Linux / macOS / Windows with GLFW, GLM, Dear ImGui)
$ cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
$ cmake --build build --config Release --parallel
$ ./build/shadowrealm
# Android NDK (OpenGL ES 3.2 default; pass -DSHADOWREALM_ENABLE_VULKAN=ON for Vulkan)
$ cmake -S . -B build-android -DCMAKE_TOOLCHAIN_FILE=$ANDROID_NDK/build/cmake/android.toolchain.cmake -DANDROID_ABI=arm64-v8a -DANDROID_PLATFORM=android-24
$ cmake --build build-android --parallel
