# Root Cause Analysis (RCA) Methodology

> **Project:** ShadowRealm 3D — v3.0 Ascendant | **Category:** SRE, DevOps & Operational Discipline | **Last Updated:** 2026-11-25

Structured 5-Whys and fault-tree analysis for defects.

## Method

Trace every SEV-1/SEV-2 defect past the proximate symptom (e.g., broken build) to the systemic gap (e.g., missing CI job, unpinned dependency, absent unit test) and attach a regression test to prevent recurrence.
