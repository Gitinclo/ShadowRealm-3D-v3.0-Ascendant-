# Local Development Guide

> **Project:** ShadowRealm 3D — v3.0 Ascendant | **Category:** SRE, QA & Operations | **Last Updated:** 20/11/2026

Fast local setup for WebGL, Desktop C++17, and Android NDK (mirrored in `LOCAL_DEVELOPMENT.md`).

## WebGL Dev Loop

```bash
npm install
npm run dev      # http://localhost:3000
npm run lint     # tsc --noEmit
npm test         # 7 unit tests
npm run build    # production dist/
```

## Desktop & Android Native Loop

```bash
# Strict C++17 header verification
printf '#include "Causality.h"\n' | g++ -std=c++17 -Wall -Wextra -Werror -x c++ -fsyntax-only -I. -

# Desktop OpenGL 3.3 Core build (requires GLFW 3.3+, GLM, Dear ImGui, CMake >= 3.18)
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --config Release --parallel
```

See `BUILD_SYSTEM.md` and `README.md` for full CMake Desktop and Android NDK instructions.
